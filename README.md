# Hi, I'm Dan (Đào Minh Dân) 👋

Computer Science student at Ton Duc Thang University, focused on **Computer Vision and Edge AI systems**.

I build practical machine-learning and computer-vision pipelines, then study how to evaluate and run them reliably on Linux-based edge devices. My current work connects data and model evaluation with Python/C++ systems and Raspberry Pi 5 deployment.

## Current focus

- **Computer Vision:** image processing, object detection, pattern recognition, and evaluation
- **Edge AI:** preprocessing, inference, latency/resource measurement, and deployment on Raspberry Pi 5
- **Systems:** C++, Python, Linux, CMake/CTest, process and resource management
- **Applied ML:** dataset quality, baselines, train/validation/test design, and error analysis
- **Exploring:** applied NLP/LLM systems, including retrieval and tool-calling workflows

Computer Vision and Edge AI are my current primary direction. Applied NLP/LLM systems are a secondary area I am exploring through bounded projects and competitions.
